# 수동동기화 폴더

`qc/qc_main.html`의 CSV 수동 동기화 화면에서 **"⬇ 파일로 다운로드"** 버튼을 누르면 생기는
`{섹션}.json` 파일을 여기에 넣고 GitHub Desktop으로 커밋·푸시하는 용도의 폴더입니다.

- 이 폴더의 파일들은 **GAS/UrlFetch를 전혀 거치지 않습니다.** 자동 동기화(새벽 1시)나
  기존 CSV 수동 동기화(GAS 경유)가 UrlFetch 할당량 초과 등으로 막혔을 때, 이 방법으로
  올린 데이터가 즉시 대시보드에 반영됩니다.
- 파일명은 반드시 섹션 키와 동일해야 합니다: `가전.json`, `가전외AS.json`, `반품마감.json`,
  `반품율.json`, `반품검사.json`, `반품처리.json`, `휴가일정.json`, `택배출고.json`
- 각 파일은 `{ records: [...], lastSynced: "ISO시각" }` 형태이며, 대시보드 각 페이지는
  `qc/qc_data.json`의 해당 섹션과 이 폴더의 같은 이름 파일 중 **`lastSynced`가 더 최신인 쪽을
  자동으로 사용**합니다. 즉, 다음 자동 동기화가 성공해서 `qc/qc_data.json`이 이 파일보다
  최신이 되면 자동으로 원래대로 돌아가므로, 여기 파일을 수동으로 지울 필요는 없습니다
  (지저분해지지 않게 가끔 정리해주는 것은 괜찮습니다).
